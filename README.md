# Adab Real Estate Agency

Business assets and brand kit for **Adab Real Estate Agency** — a professional real estate agency operating in Nigeria.

## What's in this repo

- **Brand logos** — full logo (PNG), icon mark (SVG), favicon
- **Design tokens** — CSS variables for consistent styling
- **Print templates** — business card and letterhead (HTML → PDF)
- **Brand hub** — [`index.html`](index.html) preview of all assets

## Quick start

1. Open `index.html` in a browser to preview the brand kit.
2. Edit contact details in [`assets/brand/site-config.js`](assets/brand/site-config.js).
3. Print templates from `assets/templates/` (Ctrl+P → Save as PDF).
